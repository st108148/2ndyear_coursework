# 2ndyear_coursework

Код к курсовой работе второго курса по анализу сейсмических данных и выделению разрывных нарушений.
Ноутбуки рассчитаны прежде всего на запуск в Google Colab и работают с сейсмическим кубом/набором трасс в формате SEG-Y.

## Содержимое

| Файл | Назначение | Статус |
|---|---|---|
| `semblance.ipynb` | Сравнение semblance (Marfurt) и eigenstructure coherence на нескольких фрагментах сейсмического разреза | Основной метод курсовой |
| `gaussian.ipynb` | Оценка локальной ориентации волнового поля и гауссова селекция элементов с заданным углом | Основной метод курсовой |
| `spectre.ipynb` | Локальный спектральный анализ (STFT) + PCA спектральных признаков | Экспериментальный, в основной текст курсовой не включён |
| `cv.ipynb` | Classical CV baseline: Canny + Hough для поиска линейных кандидатов | Экспериментальный |
| `coursework1204.pdf` | Текст курсовой работы | — |

## SEG-Y данные

Сам SEG-Y файл в репозитории не хранится. Ноутбуки по умолчанию ожидают его на Google Drive:

```text
MyDrive/cw_data/TrainingData_Image.segy
```

После подключения Google Drive полный путь в Colab выглядит так:

```python
SEGY_PATH = Path('/content/drive/MyDrive/cw_data/TrainingData_Image.segy')
```

Если файл находится в другой папке, достаточно изменить константу `SEGY_PATH` в начале нужного ноутбука.
Не рекомендуется добавлять большой SEG-Y файл в Git-репозиторий.

## Запуск в Google Colab

1. Открой нужный `.ipynb` в Google Colab.
2. Помести `TrainingData_Image.segy` в папку `MyDrive/cw_data/` либо измени `SEGY_PATH`.
3. Выполни ячейки сверху вниз. Первая служебная ячейка подключит Google Drive и установит недостающие библиотеки.
4. Если используется другой SEG-Y, проверь размеры фрагментов и параметры окон перед интерпретацией результатов.

## Методические замечания

- `semblance` и `eigenstructure coherence` измеряют локальную непрерывность сигнала. Низкая когерентность может быть связана с разломом, но не является его однозначным признаком.
- Гауссова селекция усиливает элементы с выбранной локальной ориентацией. Угол в ноутбуке задаётся в координатах изображения; без учёта физических шагов сетки он не является истинным углом падения в пространстве.
- `spectre.ipynb` теперь рассматривается как исследовательский спектральный эксперимент. PCA компонент локальных спектров может быть полезен для стратиграфических/фациальных изменений, но не используется как прямой детектор разломов.
- В старом CV-эксперименте использовалась разметка изображений, которая не сохранилась. Поэтому текущий `cv.ipynb` не имитирует отсутствующий ground truth, а реализует воспроизводимый классический CV baseline непосредственно из SEG-Y.
